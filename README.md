# Nexo

Personal macOS menu bar app that unifies window switching (AltTab-based), keep awake, window snapping, per-app input source, system monitor, simulator launcher and more.

```sh
Scripts/make-signing-cert.sh   # once: stable local code-signing identity
Scripts/build.sh Debug --run   # build and launch
```

Requires macOS 26+, Xcode 27, XcodeGen (`brew install xcodegen`). Licensed under GPL-3.0; see `NOTICE.md` for third-party credits.
